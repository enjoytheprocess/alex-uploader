Privacy policy

Alex Nguyen Uploader is a private tool used only by its owner to upload videos and thumbnails to the owner's own YouTube channel.

It uses the YouTube Data API with the owner's permission to upload videos, set thumbnails and read the channel's own video status. It does not collect, store, sell or share data about anyone else. The sign-in token stays on the owner's computer.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
